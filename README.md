# Quiver releases

Download the newest version from [Releases](https://github.com/ThunderBay/quiverPDMReleases/releases/latest).
You only need to install once. After that, Quiver updates itself.

## Windows

1. Download `Quiver_<version>_x64-setup.exe` and run it.
2. Windows SmartScreen may say "Windows protected your PC" because the installer
   is not code-signed. Click **More info**, then **Run anyway**.
3. If the old Electron version of Quiver is open, close it first.

Every update is checked against Quiver's signing key before it installs.
